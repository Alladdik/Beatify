# Beatify для телефону

Окремої мобільної версії коду більше немає: **інтерфейс один** (`../client`), а ця папка — лише Capacitor-обгортка,
яка пакує його в нативний застосунок iOS / Android.

## Найпростіше: PWA
Відкрийте сайт Beatify у Safari (iPhone) або Chrome (Android) → «Додати на початковий екран».
Працює як застосунок: повноекранний режим, іконка, офлайн-оболонка, медіа-кнопки на екрані блокування.

## Нативний застосунок (Capacitor)
```bash
cd mobile
npm install
npx cap add ios        # або: npx cap add android   (один раз)
npm run ios            # збирає ../client і відкриває Xcode
npm run android        # збирає ../client і відкриває Android Studio
```

При першому запуску застосунок попросить **адресу сервера** (наприклад `https://music.example.com` або
`http://192.168.1.10:5000` у домашній мережі). Змінити її можна в Профіль → Налаштування → Сервер.

Офлайн-завантаження зберігаються у файловій системі застосунку (Capacitor Filesystem) і грають без інтернету.
