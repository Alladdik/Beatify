# 📱 Beatify Mobile — Інструкція для ПК та iPhone

Ця версія додатка знаходяться в окремій папці `mobile/` і розроблена спеціально для **iPhone (iOS)** та зручного **тестування на ПК**.

Основа проєкту (`client/`, `server/`, `electron/`) залишилась повністю недоторканою.

---

## ✨ Основні можливості Beatify Mobile:

1. **100% Оффлайн Режим (Локальне сховище)**:
   - Всі скачані треки та аудіофайли зберігаються прямо на пристрої (IndexedDB у браузері ПК / Filesystem на iPhone).
   - Можна слухати музику без інтернету.

2. **Підключення до ПК-сервера по Wi-Fi**:
   - Введіть IP вашого ПК (наприклад `http://192.168.1.100:5000`) в розділі "Сервер".
   - Стрімте та завантажуйте треки з вашого C# сервера на телефон в 1 клік.

3. **Підтримка фонового відтворення на iPhone (Lock Screen)**:
   - Обкладинка, назва треку, кнопки Пауза/Плей/Далі відображаються на заблокованому екрані айфона.

---

## 💻 КРОК 1: Запуск та тестування на ПК (у браузері)

1. Відкрийте термінал у папці `mobile`:
   ```bash
   cd mobile
   ```

2. Встановити залежності:
   ```bash
   npm install
   ```

3. Запустити локальний сервер розробки:
   ```bash
   npm run dev
   ```

4. Відкрийте у браузері ПК: **`http://localhost:5174`**
   - Ви зможете перевірити інтерфейс, відтворення звуку, завантаження треків локально та створення плейлистів.

---

## 📱 КРОК 2: Миттєве тестування з iPhone по Wi-Fi (Без збірки)

1. Переконайтеся, що ваш ПК та iPhone підключені до **одного Wi-Fi**.
2. Запустіть `npm run dev` у папці `mobile`. У терміналі з'явиться адреса вашої мережі (наприклад `http://192.168.1.15:5174`).
3. Відкрийте браузер **Safari на iPhone** і перейдіть за цією адресою.
4. Натисніть кнопку **"Поділитися"** у Safari -> **"На початковий екран" (Add to Home Screen)**.
   - Тепер додаток відкриватиметься на iPhone як повноцінна програма!

---

## 🛠 КРОК 3: Збірка нативного додатка для iPhone (Capacitor iOS App)

Щоб зробити з Beatify справжній нативний iOS `.app` / `.ipa`:

1. У папці `mobile` зберіть проєкт:
   ```bash
   npm run build
   ```

2. Додайте платформу iOS (потрібен Mac з Xcode):
   ```bash
   npx cap add ios
   npx cap copy ios
   ```

3. Відкрийте проєкт у Xcode:
   ```bash
   npx cap open ios
   ```

4. **Встановлення на iPhone:**
   - **Через Xcode**: Підключіть iPhone до Mac кабелем, виберіть ваш пристрій і натисніть **Run (Command + R)**.
   - **Без Mac (Windows)**: Можна зкомпілювати `.ipa` через безкоштовний **GitHub Actions runner** і встановити на iPhone через **AltStore** або **Sideloadly**.

## 📂 Структура файлів папки `mobile/`:

- `src/lib/storage.js` — Локальне сховище (IndexedDB / Filesystem).
- `src/lib/mediaSession.js` — Інтеграція із заблокованим екраном iOS.
- `src/api/mobileApi.js` — Гібридний API (Сервер + Оффлайн).
- `src/pages/` — Екрани Головна, Пошук, Завантаження, Медіатека, Налаштування сервера.
